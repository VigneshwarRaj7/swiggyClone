# Swiggy Clone

## Overview
Swiggy Clone is a React-based web application designed to mimic the functionality of Swiggy, a popular food delivery service. This project is built using **React, Redux Toolkit, React Router, and Tailwind CSS**, providing a modern and scalable front-end architecture.

## Features
- **React 18** for modern UI development
- **React Router DOM** for seamless navigation
- **Redux Toolkit** for state management
- **Jest & React Testing Library** for unit testing
- **Tailwind CSS** for styling
- **Webpack & Babel** for modern JavaScript transpilation

## Installation
To get started with the project, clone the repository and install the dependencies:

```sh
git clone https://github.com/yourusername/swiggy-clone.git
cd swiggy-clone
npm install
```

## Available Scripts

### Start the Development Server
```sh
npm start
```
Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Build for Production
```sh
npm run build
```
Builds the app for production and optimizes it for best performance.

### Run Tests
```sh
npm test
```
Runs tests using Jest.

### Watch Tests
```sh
npm run eatch-test
```
Runs tests in watch mode.

### Eject Configuration
```sh
npm run eject
```
Removes the create-react-app configuration, allowing full control over Webpack, Babel, etc.
